# Инструкция по настройке SSH-ключей (PuTTY + AdminVPS)

Эта шпаргалка поможет быстро настроить безопасный вход по SSH-ключу без ввода пароля для современных операционных систем (включая **Ubuntu 24.04** и новее), где старые RSA-ключи заблокированы по умолчанию.

---

## Шаг 1. Генерация современного ключа в PuTTYgen

1. Запустите программу **PuTTYgen** (входит в комплект PuTTY).
2. В нижней части окна в блоке **Parameters** выберите тип ключа: **Ed25519**.
3. Нажмите кнопку **Generate**.
4. Хаотично водите курсором мыши по пустому пространству окна, пока заполняется зеленая шкала.
5. **Пароль для ключа (Key passphrase):** 
   * *Если хотите вход в 1 клик вообще без паролей:* Оставьте поля `Key passphrase` и `Confirm passphrase` **абсолютно пустыми**.
   * *Если хотите максимальную защиту компьютера:* Придумайте и введите пароль (его нужно будет вводить на ПК при каждом запуске PuTTY).
6. Нажмите кнопку **Save private key** и сохраните файл в надежное место (рекомендуется создать простую папку без кириллицы, например: `C:\keys\private_key.ppk`).
7. **Важно:** Не закрывайте окно программы! Выделите и **скопируйте весь текст** из верхнего поля *«Public key for pasting into OpenSSH authorized_keys file»* (он начинается на `ssh-ed25519...`).

---

## Шаг 2. Привязка ключа на текущем сервере

Чтобы текущий сервер начал впускать вас по новому ключу, добавьте его вручную:

1. Зайдите на сервер через PuTTY как обычно (по старому паролю).
2. Откройте файл разрешенных ключей:
   ```bash
   nano ~/.ssh/authorized_keys
   ```
3. Удалите старые нерабочие ключи (если они там есть), нажмите **правую кнопку мыши**, чтобы вставить скопированный из PuTTYgen публичный ключ `ssh-ed25519...`.
4. Нажмите комбинацию клавиш **`Ctrl + O`**, затем **`Enter`** (для сохранения изменений).
5. Нажмите **`Ctrl + X`** (для выхода из редактора).
6. Задайте жесткие права безопасности, чтобы сервер не игнорировал ключ:
   ```bash
   chmod 700 ~/.ssh
   chmod 600 ~/.ssh/authorized_keys
   ```

---

## Шаг 3. Настройка и сохранение сессии в PuTTY

Чтобы PuTTY запомнил ваш ключ и логин навсегда:

1. Откройте **PuTTY**. В списке по центру выберите вашу сессию и нажмите **Load** (Загрузить).
2. В левом меню перейдите в раздел **Connection** ➔ **Data**. В поле **Auto-login username** введите имя пользователя (например, `root` или `ubuntu`).
3. В левом меню перейдите в раздел **Connection** ➔ **SSH** ➔ **Auth** ➔ **Credentials**.
4. В поле *«Private key file for authentication»* нажмите **Browse...** и укажите путь к вашему файлу `C:\keys\private_key.ppk`.
5. **Главный шаг:** Вернитесь в левом меню на самый верхний пункт **Session**. Нажмите кнопку **Save** (Сохранить) справа, чтобы зафиксировать изменения.
6. Нажмите **Open** для проверки — вход должен произойти автоматически.

---

## Шаг 4. Добавление ключа в панель AdminVPS (для будущих серверов)

Чтобы этот ключ автоматически устанавливался на все новые серверы при покупке или переустановке ОС:

1. Авторизуйтесь в личном кабинете **AdminVPS**.
2. Перейдите в раздел **Товары/Услуги** ➔ **Виртуальные серверы** (или найдите отдельную вкладку **SSH-ключи**).
3. Нажмите кнопку **Добавить ключ** / **Создать**.
4. Укажите любое имя (например, `my-home-pc`) и вставьте в поле содержимого ваш публичный ключ (`ssh-ed25519...`).
5. Нажмите **Сохранить**.

---

## 🔒 Шаг 5. Отключение входа по паролю (Необязательно)

Когда вы убедитесь, что вход по ключу работает идеально, можно полностью заблокировать вход по обычному паролю для защиты от хакеров:

1. Откройте конфигурацию SSH: `sudo nano /etc/ssh/sshd_config`.
2. Найдите строку `PasswordAuthentication` (если перед ней стоит знак `#`, удалите его).
3. Измените значение на `no`:
   ```text
   PasswordAuthentication no
   ```
4. Сохраните файл (`Ctrl+O`, `Enter`, `Ctrl+X`) и перезапустите службу SSH:
   ```bash
   sudo systemctl restart ssh
   ```
   *(После этого войти на сервер без вашего `.ppk` файла будет физически невозможно).*
